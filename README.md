# Mini MOBA — тестовая версия для GitHub Pages

Для запуска открой опубликованный GitHub Pages URL.

Содержимое папки загружается в **корень** репозитория.
Весь графический набор встроен в `assets-data.js` — отдельная папка assets не нужна.
Phaser загружается из внешнего CDN (требуется интернет).
На GitHub Pages интеграция Яндекс SDK отключена: реклама и онлайн-лидерборд
работают только после публикации на Яндекс Играх.
